# Журнал обучения: проблемы, решения и вопросы (Часть 2)

### 🛠 Технические сложности и их решения

*   **Конфигурация Tailwind CSS v4 и кастомные шрифты**
    *   **Глобальная сложность:** Незнание того, как «подружить» шрифтовую систему Next.js с новым движком Tailwind v4 без привычного файла конфигурации.
    *   **Решение:** Вместо создания `tailwind.config.mjs` мы использовали возможности v4, прописав директиву `@theme` прямо в `globals.css`. Это связало CSS-переменную шрифта `--font-onest` с системным классом `font-sans`.

*   **Ошибка «Module not found» при импорте стилей**
    *   **Глобальная сложность:** Проблема относительных путей при изменении архитектуры проекта (перенос страниц вглубь папок `app/i/am/`).
    *   **Решение:** Вынос `layout.tsx` на уровень выше (в корень папки `app`). Это восстановило корректную работу путей `import "./globals.css"` и позволило стилям применяться ко всем вложенным страницам автоматически.

*   **Динамическая стилизация и «исчезающие» цвета Tailwind**
    *   **Глобальная сложность:** Ограничение Tailwind на динамическую сборку строк (например, `bg-${color}-600`), из-за которого неиспользуемые явно классы вырезаются из финальной сборки (Purge CSS).
    *   **Решение:** Решили не делать.

*   **«Прыгающий» интерфейс при появлении новых элементов**
    *   **Контекст:** Кнопка «Сбросить» появлялась под основной кнопкой и сдвигала весь контент страницы вверх/вниз.
    *   **Решение:** Создание пустого контейнера-заглушки с фиксированной высотой (`h-12`). Теперь место под кнопку зарезервировано заранее, и её появление не нарушает центровку страницы.

### ❓ Ответы на важные концептуальные вопросы

*   **В чем разница между структурой проекта с папкой `src` и без неё?**
    Выяснили, что папка `src` — опциональна. В Next.js можно хранить папку `app` как в корне, так и внутри `src`. Это влияет только на пути импорта, но не на функциональность.

*   **Что такое директива `'use client'` и зачем она нужна?**
    Разобрали концепцию **Client Components**. Без этой строки нельзя использовать интерактивность (клики), состояния (`useState`) и браузерные API, так как Next.js по умолчанию рендерит всё на сервере как статику.

*   **Как работает Git при вложенных папках?**
    Разобрали механизм поиска корня репозитория (поиск папки `.git` вверх по дереву каталогов). Научились определять реальный корень проекта командой `git rev-parse --show-toplevel`.

*   **Как программно управлять русской грамматикой?**
    Для автоматической смены окончаний («раз», «раза») была внедрена библиотека `plural-ru`. Это позволило избежать написания сложных условий для обработки чисел типа 11, 22, 5 и т.д.
